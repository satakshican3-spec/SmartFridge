# ScrapChef: Waste-Less Kitchen
**A data-driven sustainability tool designed to reduce household food waste and maximize grocery utility.**

ScrapChef is a digital inventory application built to help users manage their kitchen resources more efficiently. It uses predictive logic to track food shelf-life, helping students and families reduce their environmental impact and lower grocery expenses.

## The Problem
Avoidable food waste is a significant economic and environmental issue in Canada. ScrapChef addresses this through:
- Predictive Expiration Alerts: Using shelf-life benchmarks to notify users before food spoils.
- Recipe Intelligence: Suggesting meals based on current inventory to ensure all ingredients are utilized.

## Key Features
- Smart Inventory Tracking: Log grocery items with pre-calculated shelf-life data.
- Dynamic Status Alerts: Visual warnings for items that need to be used within a 48-hour window.
- Zero-Waste Recipe Engine: Conditional logic suggests practical meals based on current fridge contents.
- Inventory Management: Track consumed items and remove them from the digital pantry in real-time.

## Tech Stack
- Language: Python
- Framework: Streamlit
- Logic: Time-delta predictive modeling and conditional inventory management.
